# 🔐 Analisador de Logs

Projeto de estudo em Python voltado para análise de registros de autenticação.

## 🎯 Objetivo

Criar uma ferramenta capaz de analisar logs fictícios de autenticação e identificar eventos que possam merecer investigação.

## 🧠 Conceitos praticados

- Python
- Leitura de arquivos
- Strings
- Condicionais
- Estruturas de repetição
- Manipulação de dados
- Análise de eventos de autenticação

## ⚠️ Observação

Este projeto utiliza dados fictícios e foi desenvolvido exclusivamente para fins educacionais.
